# MINDCREST UNIVERSE

안녕하세요! 이곳은 Quartz 기반으로 구축된 디지털 가든입니다.

## 시작하기

이 프로젝트는 옵시디언 노트를 웹사이트로 시각화하여 지식 연결망(Graph View)을 구현하는 것을 목표로 합니다.

## 샘플 노트

- [[hello-world]] - 첫 번째 샘플 노트
- [[knowledge-management]] - 지식 관리에 대한 생각

## 기능

- **Graph View**: 노트 간의 연결을 시각화
- **검색**: 전체 텍스트 검색 지원
- **태그**: 주제별로 노트 분류
- **반응형 디자인**: 모든 기기에서 최적화된 경험
